## 🔄 How to Update Branding

1. Go to **Admin Settings → General**
2. Navigate to **Branding & Theme** section
3. Update:
   - Logo URL (if using custom logo)
   - Primary Color (currently: #dc2626)
   - Secondary Color (currently: #1f2937)
   - Company Address
   - Company Description
4. Add Social Media Links (optional)
5. Click **Save Settings**

All changes will be automatically applied to:
- ✅ All email templates
- ✅ Website footer
- ✅ Contact pages
- ✅ Terms & Privacy pages
- ✅ Email headers and footers

## 🎨 Design Guidelines

### When to Use Primary Color (Red #dc2626)
- Primary action buttons
- Important links
- Call-to-action elements
- Email headers
- Status indicators (errors, warnings)
- Brand highlights

### When to Use Secondary Color (Gray #1f2937)
- Body text
- Secondary buttons
- Borders
- Subtle backgrounds
- Footer text
- Secondary information

### Logo Usage
- Always use the official logo from `/gritsync_logo.png`
- Maintain aspect ratio
- Minimum size: 48x48px for emails
- Recommended size: 128x128px for headers
- Use on white or light backgrounds for best visibility
