# AI-Powered Newsletter Builder

## Overview
The AI-Powered Newsletter Builder is an advanced component that allows administrators to create professional newsletters and broadcasts with AI assistance. It integrates seamlessly with the email campaigns system and scheduled email queue.

## Features

### ✨ AI Content Generation
- **Smart Content Generation**: Generate newsletter content using AI based on simple prompts
- **Multiple Templates**: Choose from Professional, Modern, or Minimal design templates
- **Automatic Subject Lines**: AI generates compelling subject lines and preheader text
- **Time-Saving**: Create professional newsletters in minutes, not hours

### 📝 Step-by-Step Wizard
1. **Details & AI**: Set campaign name, type, and generate content with AI
2. **Content**: Fine-tune subject, preheader, and HTML content
3. **Recipients**: Choose who receives the newsletter (subscribers, users, custom)
4. **Schedule**: Set the date and time for sending
5. **Preview**: Review before scheduling

### 🎯 Campaign Types
- **Newsletter**: Regular updates and content for subscribers
- **Broadcast**: One-time announcements to all users
- **Announcement**: Important updates and alerts
- **Promotional**: Marketing and promotional content

### 📊 Integration
- **Email Queue**: Automatically schedules emails in the queue system
- **Campaign Tracking**: Links to campaign analytics for performance tracking
- **Recipient Management**: Integrates with subscriber and user systems

## Usage

### Accessing the Builder
1. Navigate to `/admin/emails`
2. Click on the **Campaigns** tab
3. Click **AI Newsletter Builder** button

### Creating a Newsletter

#### Step 1: Details & AI Generation
1. Enter a newsletter name (e.g., "Monthly Newsletter - December 2024")
2. Select campaign type (Newsletter or Broadcast)
3. In the AI section:
   - Describe your newsletter content in the text area
   - Select a template style (Professional, Modern, or Minimal)
   - Click "Generate Content with AI"

**Example Prompts:**
- "Monthly update about NCLEX preparation tips and success stories"
- "Announcement of new features and improvements to the platform"
- "Holiday greetings and year-end review for our community"

#### Step 2: Content Customization
- Edit the **Subject Line** (auto-generated by AI)
- Modify the **Preheader Text** (preview text in inbox)
- Fine-tune the **HTML Content** (generated by AI or write your own)

#### Step 3: Select Recipients
Choose who will receive the newsletter:
- **All Subscribers**: Everyone subscribed to your newsletter
- **All Users**: All registered users
- **Custom List**: Specific recipient list (future feature)

#### Step 4: Schedule
- Select the date and time when the newsletter should be sent
- The system will queue the emails for delivery at the scheduled time

#### Step 5: Preview & Schedule
- Review your newsletter content
- Check the subject line and preview
- Click "Schedule Newsletter" to queue for sending

### Save as Draft
At any step, you can save your progress as a draft:
- Click "Save Draft" button in the footer
- The campaign will be saved with status "draft"
- You can resume editing later from the Campaigns list

The current implementation uses template-based generation. To integrate with real AI services:

1. **OpenAI Integration**:
```typescript
import OpenAI from 'openai'

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY })

const completion = await openai.chat.completions.create({
  model: "gpt-4",
  messages: [
    {
      role: "system",
      content: "You are a professional email newsletter writer..."
    },
    {
      role: "user",
      content: aiPrompt
    }
  ]

```

2. **Anthropic Claude Integration**:
```typescript
import Anthropic from '@anthropic-ai/sdk'

const client = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY })

const message = await client.messages.create({
  model: "claude-3-sonnet-20240229",
  max_tokens: 1024,
  messages: [{
    role: "user",

```

### Database Schema

**email_campaigns** table:
- Stores campaign metadata, content, and statistics
- Links to scheduled emails via metadata

**email_queue** table:
- Stores individual emails to be sent
- References campaign_id in metadata
- Managed by the email queue system

- View all campaigns with status badges
- See campaign type (Newsletter, Broadcast, etc.)
- Check scheduled date and recipient count

- View detailed statistics for sent campaigns

## Best Practices

### Content Writing
1. **Subject Lines**: Keep under 50 characters for mobile visibility
2. **Preheader**: Use 80-100 characters to complement the subject
3. **Content**: Balance text and images, ensure mobile responsiveness
4. **Call-to-Action**: Include clear, prominent CTAs

### Scheduling
1. **Timing**: Send during optimal hours (9-11 AM or 1-3 PM local time)
2. **Frequency**: Don't overwhelm subscribers (weekly or monthly is good)
3. **Testing**: Send test emails before scheduling to all recipients

### AI Prompts
Write clear, descriptive prompts:
- ✅ Good: "Monthly newsletter featuring NCLEX tips, success stories, and upcoming webinar announcement"
- ❌ Bad: "newsletter"

### Recipient Management
1. Respect unsubscribe requests immediately
2. Segment audiences for targeted content
3. Monitor bounce rates and clean lists regularly

## Troubleshooting

### AI Generation Not Working
- Check if the prompt is descriptive enough
- Try a different template style
- Ensure all required fields are filled

### Scheduling Fails
- Verify scheduled date is in the future
- Check recipient type is valid
- Ensure email_queue table exists in database

### Preview Not Displaying
- Check HTML content is valid
- Ensure no JavaScript in email content
- Verify inline CSS for email compatibility
