Cursor-Based Pagination:
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│  Page 1: Emails 1-50                                                    │
│  nextCursor: "email_50_id"                                              │
│                                                                         │
│  [Load More] ← Click                                                    │
│                                                                         │
│  Page 2: Emails 51-100                                                  │
│  nextCursor: "email_100_id"                                             │
│  prevCursor: "email_51_id"                                              │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

Implementation:
```typescript
// State
const [emails, setEmails] = useState<Email[]>([])
const [nextCursor, setNextCursor] = useState<string>()
const [hasMore, setHasMore] = useState(false)

// Load more
const loadMore = async () => {
  const result = await getReceivedEmailsPaginated({
    limit: 50,
    after: nextCursor
  })
  
  setEmails([...emails, ...result.emails])
  setNextCursor(result.nextCursor)
  setHasMore(result.hasMore)
}

// UI
{hasMore && (
  <button onClick={loadMore}>Load More Emails</button>
)}
```

