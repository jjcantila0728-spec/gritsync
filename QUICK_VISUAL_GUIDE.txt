Data Fetching Process:
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. Extract sender email from "from" field                              │
│    ↓                                                                    │
│ 2. Query Supabase users table by email                                 │
│    ↓                                                                    │
│ 3. Get: first_name, middle_name, last_name, avatar_path                │
│    ↓                                                                    │
│ 4. Build full name: "John Michael Doe"                                 │
│    ↓                                                                    │
│ 5. Get signed URL for avatar from Supabase storage                     │
│    ↓                                                                    │
│ 6. Fallback: Use email name if no DB match                             │
│    ↓                                                                    │
│ 7. Fallback: Show gradient avatar with initials                        │
└─────────────────────────────────────────────────────────────────────────┘
